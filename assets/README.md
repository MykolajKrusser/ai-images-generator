# Generated Assets

This directory contains assets generated by the Diffusers API.

## Directory Structure

- `/img`: Contains generated images from the text-to-image endpoint

The files are named using the format: `YYYYMMDD_HHMMSS_prompt_slug.png`

Where:
- `YYYYMMDD_HHMMSS` is the timestamp when the image was generated
- `prompt_slug` is a simplified version of the text prompt used to generate the image

## Accessing Images

Images can be accessed directly through their URL path:

```
http://localhost:8000/assets/img/FILENAME.png
```

Or you can get a list of all generated images by calling:

```
GET /images/list
```

This will return a JSON response with information about all available images.
